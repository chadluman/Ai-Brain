# Archive Map

This folder holds superseded material retained for history. It is not a place to select from for new work.

## How material moves here

1. Update the source note first, so there is one current version of the guidance.
2. Mark the superseded note `deprecated` (still present for transition, but should not be selected for new work) or `retired` (historical only).
3. Link from the superseded note to its replacement, and from the replacement back to it where that helps explain a change.
4. Move the superseded note here, and remove it from active navigation maps. Do not leave a second, contradictory copy in an active folder.
5. Record the change, why, the date, and any migration impact in the [Maintenance Log](../00-System/Maintenance%20Log.md).

## Rules for archived material

- Do not use an archived skill, playbook, catalog entry, or pattern for a new project without a fresh review and a decision to bring it back into active use.
- Do not edit an archived note in place to make it current. Restore it to an active folder, update it there, and record the change.
- Keep archived notes readable and linked. Archiving is for history and for explaining past decisions, not for deleting evidence.

## Archived material

No archived notes exist yet in this snapshot. That is expected: this folder starts with this map only, and gains notes only when active material is superseded.
