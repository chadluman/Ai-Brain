## Recommended Sequence

COITB's full-stack article recommends this sequence, and this pathway follows it:

1. **HTML-CSS Web Designer** — structure and styling.
2. **JavaScript Professional Developer** — language and interactivity.
3. **ReactJS Framework Developer** — component-based front-end development.
4. **MySQL Backend Developer** — relational back-end development.

COITB presents these as individually stackable credentials, each a separate, independently proctored exam with its own digital badge, not as a single bundled full-stack exam. Candidates can also add Professional Python Developer and Certified GPT Professional for broader back-end and AI coverage. Technical Sales Specialist sits outside the developer sequence; place it by the learner's career goal, not by the developer dependency order.

## What Is NOT Verified Here

- No COITB exam-outline page for JavaScript, React, MySQL, Python, or Technical Sales was located on 2026-11-02, so this pathway does not claim official domain weights for those credentials. Each individual skill records its own verification status.
- The GPT Professional credential's logistics are not restated here; use that skill's own blueprint, which was verified against its own sources.
- This pathway does not claim that one credential is a formal prerequisite for the next. The sequence is COITB's recommended dependency order.

## Pathway Interpretation

- Work one credential at a time. A learner who can build a page is not automatically ready for JavaScript, and a learner who can write JavaScript is not automatically ready for React or MySQL.
- Carry projects forward only where they genuinely help: a learner's HTML/CSS site can gain JavaScript interactivity, then a React version, then a MySQL-backed data layer. Do not force a single project to serve a credential it does not fit.
- Set a readiness gate between credentials: the previous credential's capstone and practice evidence, plus the next credential's diagnostic, before committing to the next exam date.
- If a credential is delayed, adjust only that credential and its dependents. Do not restart the whole pathway.

Record the new verification date and what changed; do not silently carry the old list forward.
