# COITB ReactJS Framework Developer Exam Blueprint

Verified against official COITB pages on 2026-11-02. Recheck immediately before a study plan, mock exam, registration decision, or claim about current exam logistics.

## Credential and Exam Summary

- Official credential name: **ReactJS Framework Developer Certification**. The badge page also uses the wording "React Essentials certification" when describing what earning it demonstrates; record that wording difference rather than resolving it by assumption.
- Published length, item count, and passing score, from COITB's own full-stack article: **90 minutes, 90 items, 73%**.
- Format, from the official badge page: **multiple-choice and scenario-based items**.
- Delivery, from the official badge page: online remote proctor or authorized test center; language English; badge validity aligned to certification term.
- Recommended experience, from the official badge page: **1–6 months of hands-on practice** working with HTML, CSS, and basic JavaScript.
- Position in the COITB pathway: the third credential in COITB's recommended full-stack sequence, after HTML-CSS Web Designer and JavaScript Professional Developer and before MySQL Backend Developer.

## What COITB's Badge Page Says Learners Should Know

These are the badge page's "What you're expected to know" statements, verified 2026-11-02, and they are the verified scope anchor for this skill's curriculum:

- Understanding React components, props, and state management.
- Building reusable UI components and organizing code for maintainability.
- Managing user interactions with event handlers and controlled components.
- Working with JSX to structure interfaces and incorporate dynamic data.
- Using hooks such as `useState` and `useEffect` to handle logic and lifecycle behavior.
- Implementing routing, conditional rendering, and component composition.
- Integrating APIs and handling asynchronous data within React applications.
- Building multi-section, interactive interfaces and small-to-medium React applications.

## Exam-to-Curriculum Interpretation

- Cover every badge-page statement. Allocate practice by measured learner weakness, not by an invented weight.
- Teach code reading as well as code writing. A multiple-choice and scenario-based exam can test rendering, state updates, effect timing, and event behavior without requiring a live editor.
- Pair each area with a working project artifact. Correct answers without the ability to build and debug a React application are insufficient practical evidence.
- Teach accessibility as a cross-cutting expectation: interactive components must remain keyboard-usable and announced correctly.
- Treat advanced state libraries and server frameworks as out of scope for this credential's preparation topics. Teach local state, lifted state, and effect discipline first.

## Local Readiness Heuristic

This is a teaching heuristic, not a COITB policy or score prediction:

- complete at least three original mixed practice sets under time pressure;
- score at least 85% on each of the last two sets;
- score at least 75% within every curriculum area rather than relying on strength in one area to conceal a gap;
- explain the rationale for corrected answers without memorizing wording;
- complete the curriculum capstone acceptance criteria and diagnose at least one injected component, state, effect, routing, and API-handling defect.

If the exam date is near, prioritize high-weakness areas. If time permits, repair prerequisite gaps before increasing question volume.
