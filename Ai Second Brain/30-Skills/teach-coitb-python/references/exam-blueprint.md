# COITB Professional Python Developer Exam Blueprint

Verified against official COITB pages on 2026-11-02. Recheck immediately before a study plan, mock exam, registration decision, or claim about current exam logistics.

## Credential and Exam Summary

- Official credential name: **Professional Python Developer Certification**.
- Published length, item count, and passing score, from COITB's own full-stack article: **75 minutes, 58 items, 70%**.
- Delivery described on COITB badge pages generally: online remote proctoring or an authorized test center; language listed as English.
- Position in the COITB pathway: an add-on credential alongside the recommended full-stack sequence, broadening back-end coverage; COITB does not place it inside the four-step HTML → JavaScript → React → MySQL sequence.

## What Is NOT Verified Here

No COITB exam-outline page for this certification was located on 2026-11-02 through COITB's site search, so this blueprint does **not** claim official domain names, domain weights, or question counts by domain. The curriculum areas in the companion curriculum file are preparation topics drawn from Python practice, not a reproduction of a COITB outline. Do not present them as official domains, and do not fill the gap with weights borrowed from another vendor's Python exam.

## Exam-to-Curriculum Interpretation

- Cover every curriculum area. Allocate practice by measured learner weakness, not by an invented weight.
- Teach code reading as well as code writing. A multiple-choice and scenario-based exam can test values, control flow, data-structure results, and error handling without requiring a live interpreter.
- Pair each area with a working project artifact. Correct answers without the ability to write, run, and debug a Python program are insufficient practical evidence.
- Teach testing as a cross-cutting expectation: every capstone feature has a small test or a documented manual verification, even though no separate testing domain is claimed here.
- Treat web frameworks and data-science libraries as out of scope for this credential's preparation topics unless a located official outline says otherwise. Teach the language, standard library, and file and API handling first.

## Local Readiness Heuristic

This is a teaching heuristic, not a COITB policy or score prediction:

- complete at least three original mixed practice sets under time pressure;
- score at least 85% on each of the last two sets;
- score at least 75% within every curriculum area rather than relying on strength in one area to conceal a gap;
- explain the rationale for corrected answers without memorizing wording;
- complete the curriculum capstone acceptance criteria and diagnose at least one injected syntax, logic, data-structure, file-handling, and error-handling defect.

If the exam date is near, prioritize high-weakness areas. If time permits, repair prerequisite gaps before increasing question volume.
