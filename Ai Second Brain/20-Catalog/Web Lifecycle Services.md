# Web Lifecycle Services

A dated, comparable shortlist of concrete services, libraries, extensions, and plug-ins used across the full website lifecycle, for a solo or small-team builder on a Next.js / Vercel / Neon / Clerk / Stripe stack, with StreamControl.studio as the reference product. It complements, and does not replace, the vault's generic selection skills: use a shortlist row to narrow a decision to two or three shapes, then run the matching skill and the matching playbook (where one exists) before writing an ADR.

## How to read the cost and evidence columns

- **Verified:** the claim appears on the vendor's own docs or pricing page returned in the 2026-11-02 research run.
- **Secondary:** two or more independent secondary sources agree, but the vendor page was not opened in that run. Check before budgeting.
- **Conflict / Not verified:** sources disagree, or no vendor figure was returned. Do not quote it to a client, and do not budget on it, without opening the vendor's pricing page.
- **No catalog note approves a provider or a dependency.** Provisioning, credentials, billing, production changes, real-data operations, and deletion remain R3. Recheck pricing, quotas, regions, and security features from the vendor's own pages before an ADR is accepted.
